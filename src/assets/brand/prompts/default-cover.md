# Snowpub 品牌默认封面（公众号头条 2.35:1）

## 设计定位
Snowpub 的产品广告图，同时作为公众号文章的默认封面。读者在文章列表看到它时，应感到专业、清爽、与微信生态契合。

## 画面描述
扁平矢量风格插画。画面左侧 60% 为视觉主体：一支简约的钢笔尖（几何色块构成），笔尖末端幻化为一架纸飞机，纸飞机拖着一条由虚线构成的弧线轨迹，向右上方飞出——隐喻「本地写作 → 一键发布」。纸飞机飞行方向的右上方，留白区域放置产品名。

## 配色（活力绿方向）
- 主色：鲜亮微信绿（#07C160 附近）作为纸飞机与点缀色
- 背景：极浅的薄荷绿/米白渐变（#F2FBF6 → #FFFFFF），干净通透
- 钢笔尖：深墨绿或深灰（#1A3C34），与绿色形成稳重对比
- 轨迹虚线：中明度绿（#4CC47C）

## 文字（必须精确渲染）
- 主标题：**Snowpub**（现代无衬线、几何感、中等字重，深墨绿 #1A3C34，位于画面右上留白区，字号大）
- 副标题：**本地写作 · 一键发布**（同族无衬线、小号、中明度绿 #4CC47C，位于主标题正下方）
- 除上述文字外，画面不得出现任何其他文字、字母或水印

## 构图
- 2.35:1 宽幅。左重右轻：左侧笔尖→纸飞机主体，右上文字区，中间由飞行轨迹引导视线
- 40-60% 留白，呼吸感强
- 所有元素为几何化扁平色块，无描边或极细描边，无渐变堆砌（仅背景允许微妙渐变）

## 禁忌
- 不要真实照片质感、不要 3D 渲染、不要人物
- 不要复杂背景图案、不要多余装饰元素
- 不要出现二维码、微信 logo
