# 图片与封面

正文配图和文章封面是两条独立链路：配图跟着笔记走——编辑时只落本地，发布时才上传；封面走公众号永久素材。这一页讲清两条链路各自怎么工作，以及怎么配合。

## 粘贴 / 拖拽传图

在编辑器里直接粘贴（Cmd+V / Ctrl+V）图片或截图，或把图片文件拖进编辑器，png / jpg / gif / webp 都支持：

1. 图片自动存入笔记所在目录的 `imgs/` 子目录
2. 文件名取图片内容的 MD5 哈希前 16 位，同一张图反复粘贴只存一份——天然去重
3. 光标处插入相对路径引用，例如 `![](imgs/9f86d081884c7d65.png)`

编辑时图片只在本地磁盘上，不占公众号素材额度；点「保存草稿」时才统一上传微信 CDN，并把正文里的图片地址替换成 CDN 链接。笔记和 `imgs/` 目录放在一起，构成自包含的文章资产——Git 同步、备份、换电脑都随笔记目录整体迁移。

::: tip
不止 `imgs/`：正文里任何本地相对路径的图片（手动放进笔记目录的子文件夹也一样）都会在保存草稿时上传。外链图片地址则原样保留在正文里，不做转存。
:::

## 素材库

「图片素材库」浏览和管理公众号的永久图片素材，有两个入口：

- 发布对话框的封面区（见下一节）
- 图文（图片消息）模式的图片列表（可多选追加）

素材库里的操作：

| 操作 | 说明 |
|---|---|
| 上传图片 | 选择本地文件（jpg / png / gif / webp）上传为公众号永久素材 |
| 刷新素材 | 拉取最新素材列表，每页 20 张，右上角显示已加载 / 总数 |
| 点选卡片 | 选中该素材作为封面（或追加到图文图片列表） |
| 删除 | 删除素材，需二次确认 |

## 智能封面

### 封面从哪来

打开发布对话框时，封面按下面的优先级自动建议：

1. front matter 里声明的 `cover:`（本地相对路径或外链均可）
2. 正文的第一张图片
3. 内置默认封面（首次使用时自动上传到素材库并缓存，之后复用）

都不满意就在封面区点「上传图片」即时上传，或点「图片素材库」从已有素材里挑一张。同一张封面图只上传一次：源文件没变（路径、修改时间、大小一致）时直接复用已上传的素材，换篇文章用同一张封面也不会重复上传。

### 三档封面比例

封面区下方的「封面比例」提供三档预设：

| 预设 | 比例 | 适用位置 |
|---|---|---|
| 头条 2.35:1 | 900 × 383 | 群发首条、分享卡片大图 |
| 次条 1:1 | 正方形 | 群发第二条及以后 |
| 原始 | 不裁剪 | 保留原图构图 |

选「头条 2.35:1」或「次条 1:1」时，封面预览立即按所选比例居中裁切，所见即微信端的最终效果。

### 切比例不用重新上传

裁剪不在本地做：**原图完整上传一次**，所选比例换算成裁剪坐标（`cover_info`）随草稿一起提交给微信。之后切换比例只是改坐标，不重新上传图片，素材库里也不会出现裁剪副本。提交草稿后，在公众号后台编辑该草稿时仍可重新框选封面区域——Snowpub 提交的坐标只是初始建议。

封面在发布流程里的位置见[写作与发布](publish.html)——front matter 的写法与发布对话框的字段一一对应。
