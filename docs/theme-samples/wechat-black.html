主题演示

这篇演示文章用到了 Snowpub 支持的全部排版元素。切到「公众号」预览，在右上角切换 12 套主题，直观对比每套的排版风格。

文字样式

正文段落支持 粗体、斜体、删除线、行内代码，以及中英文混排 mixed content。外链会自动转成文末脚注：[1]Example 与 [2]Snowpub 仓库。

标题层级

三级标题

标题是各主题差异最大的元素：色条、居中、衬线、通栏底色，一眼可辨。

引用与代码

这是一段引用 blockquote。 引用块是主题风格的另一个分水岭。

function greet(name) {
  return `Hello, ${name}!`
}
console.log(greet('snowpub'))
