snowpub

本地优先的微信公众号写作与发布工具。用 Markdown 写作，实时预览微信样式，一键发布到公众号。

⬇ 立即下载 ⭐ Star on GitHub

核心功能

✍️

双栏编辑

左侧 Markdown（CodeMirror）编辑，右侧微信样式实时预览，所见即所得。

🎨

微信主题

内置微信绿、科技黑、活力橙、默认白四套主题，随时切换。

🚀

一键发布

通过公众号官方 API：保存草稿、发布、查询发布状态，全流程本地完成。

🖼️

图片素材库

本地图片上传到公众号素材库，文章封面图选择，发布时正文图片自动上传替换。

📥

草稿箱同步

拉取、删除、直接发布公众号已有草稿，本地与云端草稿统一管理。

🔗

外链转底部引用

自动将外链转为微信友好的底部脚注，避免公众号正文外链不显示的问题。

🔄

Git 同步

支持 GitHub 和 Gitee，一键推送/拉取。版本历史随时浏览恢复。

🌐

中英双语

界面支持中文和英文切换，适合不同语言习惯的用户。
